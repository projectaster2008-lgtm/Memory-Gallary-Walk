# Local Music Files Directory

Place your 3 MP3 files in this directory (`/public/music/`):

1. `i-like-you-so-much-youll-know-it.mp3` -> "I Like You So Much, You'll Know It"
2. `somewhere-only-we-know.mp3` -> "Somewhere Only We Know"
3. `true-colors.mp3` -> "True Colors"

The application will automatically detect and play these local MP3 files when present.
If a file is not yet provided, the app will play a procedural ambient acoustic harmony and theme atmosphere, and you can also select the MP3 directly via the playlist upload button.
